# Coodsz Burning Empires

Tools that make hosting and playing Burning Empires in Bannerlord Coop easier. Made by Coodsz, with permission from the Burning Empires team.

- **Coodsz Burning Empires Server Tool** runs a Burning Empires Coop server for you.
- **Coodsz Burning Empires Client Launcher** gets your game ready and joins the server.
- **Burning Empires Coop Compat** is the patch that makes Burning Empires work in Coop. It comes with both tools.

Made for Burning Empires 2.0.2, Bannerlord 1.4.8 and Coop 0.1.6. Windows only.

## Download

Get the latest Coodsz-Burning-Empires-Tools zip from [Releases](https://github.com/Coodsz/Coodsz-BurningEmpires/releases/latest). It holds both programs. Unzip it before you open a tool. The instructions file in the release explains every step.

## Which mods work

See [MODS.md](MODS.md) for the mod list.

## Report a mod

Click **Report a mod** at the top of the Coodsz Burning Empires Client Launcher and pick Works or Broken. No GitHub account is needed. With an account you can use the [report form](https://github.com/Coodsz/Coodsz-BurningEmpires/issues/new?template=mod-compat.yml). Player reports show in the Players column of the list. Coodsz sets the status.

## Known issues

- On Coop 0.1.6, a hideout fight where your hero is knocked down never ends. This is a Coop bug, and a Coop fix is on the way.
- On Coop 0.1.6, accepting some quests can freeze the dialog. This is a Coop bug too. Coop's development version replaced that quest system.
- The campaign map ground can look black on some PCs. Burning Empires is missing a terrain shader cache file, and it happens in single player without Coop too. The Burning Empires author is looking into it.
- The Burning Empires population on your PC is a snapshot from when you join. Rejoin to update it.
